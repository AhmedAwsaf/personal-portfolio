## 🗂️ Project Categorization

### ⚡ Backend, Database Engines & Distributed Systems
- **Dynago:** Dynamic PostgreSQL REST API engine compiling HTTP requests directly to single-query JSON with zero ORM boilerplate, embedded Wazero WebAssembly plugins, PostgreSQL WAL logical replication (CDC), and Server-Sent Events (SSE).

### 📱 Mobile & Android Development
- **BossClub:** Built using modern Kotlin and Jetpack Compose for enterprise collaboration.
- **MortGame:** Built in Unity and exported to the Android SDK with intuitive touch controls.

### 🌐 Full-Stack & Enterprise Web Applications
- **Barobi Design:** E-commerce platform deployed on Google Cloud Platform with live payment processing.
- **MASROORS PLLC:** Client intake dashboard and legal case management portal.
- **CookBook:** Recipe sharing and community kitchen platform built on MongoDB, Express, React, and Node.
- **Fitness Matrix:** Workout tracker and progress visualization application.
- **MusicPill:** Playlist curator and music database built with Django and MySQL.

### 🎮 Graphics, Physics & Game Engines
- **MortGame:** 2D platforming, obstacle collision, physics parameters, and animation states in Unity.
- **DX Ball:** Retro brick-breaker written in Python directly addressing the OpenGL graphics pipeline with mathematical collision physics.
